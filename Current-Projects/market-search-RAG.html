Overview

What It Does

01 — SEARCH

Live Web Search

Fetches fresh results via the Tavily API. Reports are grounded in current data, not stale model knowledge.

02 — RAG

RAG Pipeline

Chunks and embeds content with NVIDIA NIM, then retrieves the most semantically relevant passages from a ChromaDB vector store.

03 — REPORT

Structured Reports

Outputs validated JSON with key metrics, interactive charts, sentiment scores, competitive landscape, risk factors, and an analyst verdict.

System Design

Pipeline Architecture

USER QUERY
e.g. "global EV battery market 2026"
01 DISPATCH
FastAPI /research/start → Celery task enqueued → task_id returned (202)

Client polls /status/{task_id} every 3 seconds while the worker runs async.

02 INGESTION
Tavily Web Search (8 results) → Chunking (500 tok, 100 overlap) → NVIDIA NIM Embeddings → ChromaDB upsert

nvidia/nv-embedqa-e5-v5 encodes chunks in batches of 32.

03 GENERATION
ChromaDB retrieval (top-5) → Prompt + JSON schema → NVIDIA NIM LLM → Pydantic validation

openai/gpt-oss-120b generates structured output; on schema failure the model self-corrects (max 2 retries).

04 VISUALIZATION
Structured JSON report → Next.js React frontend → Recharts (bar / line / donut) → PDF export

8-section interactive report: thesis, metrics, charts, sentiment, landscape, risks, opportunities, verdict.
