What It Does

Analytics that understands you

01

Dual-Platform Analytics

Aggregates Instagram reach and Facebook impressions into a single unified view. Break down performance by genre, emotion, topic, and date — with a genre × emotion heatmap and Pareto 80/20 identification built in.

02

Multi-Agent AI

An Orchestrator classifies every query and dispatches three specialist sub-agents in parallel: Data Connoisseur for SQL queries, Dashboard Manager for filter control, and Report Master for snapshot generation.

03

Natural Language Filtering

Ask "Show me top genres for Instagram in April" and watch the charts update live. Sub-agent progress streams to the UI via Server-Sent Events, so you see each step as it happens.

04

Instant HTML Reports

One command generates a fully self-contained HTML snapshot: charts, tables, narrative summary, and Pareto analysis — ready to download and share without any external dependencies.

How It Works

Four-tier agent pipeline

Input
User Query
Plain-English question or dashboard command, sent with current filter state as context.
↓
Orchestrator
Intent Classifier & Dispatcher
Groq llama-3.3-70b with function calling. Classifies intent (data_query, dashboard_change, report, conversation) and builds a parallel dispatch plan.
↓
Sub-agent A
Data Connoisseur
Runs 7 parallel MySQL queries (genre, emotion, trend, matrix, Pareto ×2, summary). Returns structured data insights and percentage breakdowns.
Sub-agent B
Dashboard Manager
Resolves date ranges and emits DashboardAction[] — platform, date range, topN, search — applied to React state without a page reload.
Sub-agent C
Report Master
Calls Data Connoisseur internally, then renders a self-contained HTML report with inline CSS and downloadable via a blob URL.
Results streamed to browser via Server-Sent Events — progress visible at each sub-agent step
↓
Frontend
React Dashboard
Recharts visualisations (bar, area, composed, heatmap) update reactively. Theme-aware dark/light toggle persisted in localStorage. Three.js particle background responds to mouse.
